# AGENTS.md

Guidelines for AI agents working in this repository.

## Project

MaiMai "Guess the Song" Discord quiz bot. Python 3.12, discord.py (`>=2.0.0`),
hybrid model: slash commands (`app_commands`) with a mention-prefix fallback.
Two bot processes: `bot.py` (main: cogs `quiz`, `maimai_net`, `profile`) and
`admin_bot.py` (owner-only: cog `admin`, talks to main bot via JSONL signal file).

## Commands

- Run the main bot: `.venv\Scripts\python.exe bot.py`
- Syntax check changed files: `.venv\Scripts\python.exe -m py_compile <files>`
- No test suite or linter is configured. Verify by compiling, and where
  practical, running a small async script against the venv.
- `.env` requires `DISCORD_TOKEN`; `TOKEN_SECRET` (Fernet key) is mandatory for
  any token/password encryption. Generate with
  `.venv\Scripts\python.exe -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`.

## Databases (SQLite via aiosqlite)

- `maimai_data.db` — game data only: `user_scores`, `user_profiles`, `user_inventory`.
- `segaid_accounts.db` — all login/auth data (moved here): `user_tokens`
  (encrypted clal session cookies) and `segaid_accounts` (SEGA ID username +
  encrypted password). Token functions (`save_token`/`get_token`/`delete_token`)
  live in `utils/segaid_db.py`; `init_segaid_db()` auto-migrates legacy tokens
  from `maimai_data.db` on startup.
- Follow the established idiom: one connection per call
  (`async with aiosqlite.connect(DB_PATH) as db`), parameterized `?` queries,
  explicit `await db.commit()`.
- Encryption helper `_get_fernet()` lives in `utils/database.py`.

## Conventions

- Cogs in `cogs/`, loaded in `bot.py` `setup_hook()` via `load_extension`.
- All `/login*`, `/logout`, `/fetch`, `/mystats` responses MUST be ephemeral
  (credentials/session data must never be visible in-channel).
- Long operations: `await interaction.response.defer(ephemeral=True)` first,
  then `interaction.followup.send(...)`.
- maimai NET (International) scraping: `utils/maimai_scraper.py`
  (auth gateway `lng-tgk-aime-gw.am-all.net`, 302 = valid clal cookie).
  SEGA ID credential login: `utils/segaid_login.py` (mirrors
  https://github.com/shedaniel/tomomai `performInternationalAccountLogin`).
- Never log or embed tokens/passwords. Match existing style: docstrings on
  functions, type hints, no excessive comments.

## Do NOT edit / regenerate

`output.json`, `data.json`, `images/`, `audio/`, `charts/`, `assets/`,
`sekaipedia_translations.json` — these are generated by scripts in `scripts/`
or downloaded assets. Song data queries go through `utils/song_loader.py`.
